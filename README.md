# Project 2 - Data Classification Using AI (KNN)

DecodeLabs Industrial Training Kit (Batch 2026)

## Description
A supervised learning classification model built using the Iris dataset
and K-Nearest Neighbors (KNN) algorithm.

## Features
- Iris dataset (150 samples, 3 classes, 4 features)
- 80/20 train-test split
- Feature scaling with StandardScaler
- KNN classifier (k=5)
- Evaluation: Accuracy, F1 Score, Confusion Matrix

## Result
Achieved 100% accuracy and F1 score on the test set.

## How to Run
python iris_classifier.py
